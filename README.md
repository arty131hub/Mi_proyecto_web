# Mi Proyecto Web

Sitio web estático en HTML creado para practicar Git y GitHub. Incluye navegación por secciones y ejemplos de una tabla y un formulario.

- [Instalación](#instalación)
- [Estructura](#estructura)

## Instalación

Clona el repositorio y abre `index.html` en un navegador web. No se necesitan dependencias ni servidor.

```bash
git clone https://github.com/arty131hub/Mi_proyecto_web.git
```

## Estructura

- `index.html`: contenido del sitio web.
- `.gitignore`: excluye la carpeta `.vscode/`.
- `README.md`: documentación del proyecto.

## Mejoras implementadas

- Menú de navegación con enlaces internos a las secciones de inicio, proyecto, horario y contacto.
- Tabla accesible con un horario semanal de ejemplo.
- Formulario de contacto con campos etiquetados; es solo visual y no envía datos.

## Flujo de trabajo

Las mejoras se desarrollaron en ramas independientes y se integraron mediante Pull Requests en la rama predeterminada `master`.
